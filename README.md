# TinaDesk · Windows 透明桌面小窗

两块叠在壁纸上的透明桌面小窗：

- **Tina · 今日行情**（顶部横条）：加密货币、汽油、股票指数、国内金价（沪金 99，暂不支持自定义）、人民币汇率中间价，各栏每 5 秒轮换。首次打开使用内置默认清单；在对应栏目上右键，可以自己添加或删除币种、城市油价、股票和汇率。
- **Tina · 今日任务**（右上角竖条）：经济热点、今日英文、今日羊毛，每 8 秒翻页，序号和标题同一行；本地内容每小时自动刷新一次。在今日英文上右键，可随机更换十个单词。单击经济热点或今日羊毛的标题可打开原文（若该条有链接）。

无标题栏、无边框、背景完全透明；不置顶、不挡普通窗口；左键拖动（点在标题上未拖动则打开原文）；在今日行情某一栏上右键可管理该栏内容，在今日英文上右键可随机更换十个单词，在标题或空白处右键仍是刷新 / 换色 / 立即更新 / 开机自启等菜单。右键请点在文字上：透明空白处会点穿到桌面。
换过的文字颜色、拖好的窗口位置会记在本地 `settings.json` 里，下次打开仍有效。已经在运行时再打开，会提示「已经在运行」，不会再开一份。
程序内置每日自动更新（行情 06:50 后、任务内容 07:45 后；失败每 10 分钟重试）。第一次打开、本地还没有数据时会立刻更新，不必等到整点。不需要计划任务。

> 仅支持 Windows（依赖 tkinter 的色键透明和 Win32 窗口层级）。从源码运行需要 Python 3.8 及以上，安装时请勾选 tcl/tk（tkinter）。

## 使用（直接用 exe）

1. 到本仓库的 [Releases](../../releases) 下载 `TinaDesk.exe`，放进一个固定文件夹（数据文件会生成在它旁边）。请把 exe 放到 Releases，不要提交进代码库。
2. 双击运行；右键小窗 →「开机自启：开」。若以后移动了这个文件夹，再运行一次程序即可自动更新开机自启路径。
3. 右键 →「编辑手动数据」，按里面每一行的提示填写，保存即可。

部分杀毒软件可能把 PyInstaller 打包的 exe 误报为风险，这是这类打包方式的常见情况。可以对照本仓库源码，或改用下面的「从源码运行」。

## 从源码运行

```
python desk_widgets.py        # 或 pythonw 无控制台运行；或双击 start_desk.bat
python update_data.py all --check   # 在控制台逐项检查各数据源
```

只用 Python 标准库，无需 `pip install`。若系统找不到 Python，`start_desk.bat` 会提示而不是静默退出；也可先设置 `TINA_PYW` 指向 `pythonw.exe`。数据目录默认是程序所在目录，可用环境变量 `TINA_DATA_DIR` 指定。

## 打包 exe

双击 `build_exe.bat`（需要联网安装 PyInstaller）。生成的 `TinaDesk.exe` 请上传到 GitHub Releases，不要提交进仓库。
找不到 python 时先运行：`set TINA_PY=C:\你的路径\python.exe`。

## 文件说明

| 文件 | 作用 |
|---|---|
| `desk_widgets.py` | 主程序：两个小窗 + 后台每日更新 |
| `update_data.py` | 数据抓取与写入（可单独命令行运行） |
| `ctl.py` | 命令行遥控：`python ctl.py refresh` / `python ctl.py theme 墨色` |
| `start_desk.bat` | 从源码启动（找不到 Python 时会提示） |
| `build_exe.bat` | 打包成 `TinaDesk.exe` |
| `手动数据.txt` | 不在仓库里。首次运行自动生成（汽油后备、今日羊毛、订阅源、额外单词），一般不用改 |
| `settings.json` | 不在仓库里。本地保存的文字颜色和窗口位置 |

## 数据来源与局限

- 加密货币：CoinGecko（备用 OKX）；股票/指数：腾讯行情；沪金 99：新浪行情；汇率：中国外汇交易中心中间价。
- 经济热点：RSS（默认中新网财经，备用人民日报财经，可在 `update_data.py` 的 `FEEDS_ECON` 修改）。
- 汽油价：默认西安 92# / 95#，请按自己所在城市右键添加其他城市和 98# / 0#柴油；自动读取汽车之家各地油价页（现价 + 走势表算出相对上次调价的变动）；失败时才用 `手动数据.txt` 的 `[汽油]` 给西安当后备。
- 今日羊毛：每天 10 条，分两页轮换，标题分别为「今日羊毛（优惠券）」和「今日羊毛（token）」。优惠券默认读什么值得买优惠券频道里的外卖 / 闪购（如美团外卖、淘宝闪购）；token 默认读大模型价格变动。可在 `手动数据.txt` 的 `[羊毛]` 补充或覆盖优惠券；token 一般不用手填。
- 上述接口都是第三方的，可能随时变化或限制访问；任何一项失败都会沿用上次数据，原因记在 `update.log`。
- 数据仅供桌面展示，不构成投资建议。
